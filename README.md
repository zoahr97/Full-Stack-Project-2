# Interactive Games Website

**Academic grade: 97/100**

An interactive games website built with HTML, CSS, and JavaScript. The application provides a user-friendly environment for registration, login, gameplay, and tracking each user’s activity and achievements.

The project includes client-side user authentication with validation for new and existing users, password checks, failed login attempts, and user blocking. User information, game activity, scores, and achievements are stored in Local Storage.

The main application page presents a selection of games and activities. Two fully functional games are included: one focuses on movement and animated elements with multiple difficulty levels, while the second includes internal game logic and a dynamically changing interface based on the player’s progress.

The website uses direct DOM manipulation to update the interface in real time. It was designed with separate files and modular organization for HTML, CSS, JavaScript, images, and other project resources.

## Key Features

- User registration and login
- Client-side validation and password verification
- Failed login attempt handling and user blocking
- Local Storage-based user data, scores, and activity tracking
- Dynamic DOM updates
- Two playable interactive games
- Animations and multiple game difficulty levels
- Game progress and achievement tracking
- Responsive and consistent interface design
- Modular project structure with separated HTML, CSS, JavaScript, and media files

## Technologies

**Frontend:** HTML, CSS, JavaScript  
**JavaScript Concepts:** DOM manipulation, event listeners, timers, arrays, objects, functions, dates  
**Storage:** Local Storage  
**Styling:** Flexbox, animations, transitions, pseudo-classes  
**Tools:** Git and GitHub
